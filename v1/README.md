# 语界 LinguaVerse · v1.0 快照

> 📦 v1.0.0 历史版本 · 发布于 2025-08-28
> [返回顶层 README](../README.md) · [查看 v1 设计文档](../docs/DESIGN-v1.md) · [测试记录](../docs/TESTING-v1.md)

## 一句话介绍
v1 是语界多语种教育平台的 **首次 MVP 发布**,覆盖英语(A1-B2)、日语(N5-N3)、韩语(TOPIK I-III),
提供单词 / 语法 / 听力 / 口语四大学习模块,带在线模拟注册登录、学习社区和成就系统。

```
特点: 顶部导航 SPA · 蓝色主色白底 · Mock API 在线登录 · 社区帖子板
```

## 快速运行

```bash
# 方式一: 启动任意静态服务器
cd v1/ && python3 -m http.server 8080
# 打开浏览器访问 http://localhost:8080/

# 方式二: 直接双击 index.html (大部分功能可用,TTS 部分浏览器受限)
```

## 老版本单词数据格式

```js
// v1 format (5-element tuple)
[
  "hello",           // 0: 单词 / 日韩词
  "/həˈloʊ/",        // 1: 音标 / 读音(罗马字/假名)
  "你好",            // 2: 释义
  "Hello, nice to meet you.",   // 3: 例句原文
  "你好,很高兴认识你。"         // 4: 例句译文
]
```

## 已知限制 (在 v2.0 中已升级)

1. ❌ 英语仅有 A1-B2 分级,**不包含国内四六级词汇**
2. ❌ 无间隔重复复习(SRS)算法,学过的词不会自动安排复习
3. ❌ 登录为 Mock API,账号**只存在当前浏览器**,无法跨设备同步
4. ❌ UI 是桌面后台风格,**没有移动端专属手机外壳 UI**
5. ❌ 无 PWA 离线缓存 / 无安卓原生 APK 安装包
6. ❌ 单词例句只有 1 条 / 无根词助记解析

→ **升级到 v2.0 解决了以上所有问题** 🎉
请查看顶层 `v2/` 目录或 [GitHub Release v2.0.0](https://github.com/BAIYI0324/LinguaVerse/releases/tag/v2.0.0)。
